About GA-FuL

  • Unified generic C# library for geometric algebra computations
  • Support for multiple scalar types (floating point, rational, symbolic)
  • Memory-efficient sparse multivectors
  • Metaprogramming and code generation capabilities
  • Comprehensive documentation in English and German
